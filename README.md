Precision Lens

A premium React component that provides a smooth image magnification effect on hover. Designed for modern portfolios, product showcases, galleries, and e-commerce experiences.

✨ Features

- Smooth hover magnification
- Adjustable zoom level
- Responsive design
- Lightweight and customizable
- Built with React, TypeScript, and Vite
- Easy integration into any React project

📦 Tech Stack

- React
- TypeScript
- Vite

🚀 Getting Started

Install dependencies

npm install

Start the development server

npm run dev

Build for production

npm run build

🎨 Use Cases

- Product pages
- Image galleries
- Portfolio websites
- Creative showcases
